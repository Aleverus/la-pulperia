# Evidencia local

Las copias con observaciones viven en `local/` y no se versionan.

Nombre recomendado:

```text
AAAA-MM-DD_<actividad>_vNN.xlsx
```

Antes de compartir un agregado, revisar que no incluya nombres, contactos,
cuentas, direcciones, coordenadas, chats, documentos, pagos ni ventas declaradas.
El libro maestro permanece vacío y reproducible en `../outputs/corte-5/`.
