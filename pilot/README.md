# Corte 5 — investigación y piloto

Este directorio prepara la recolección de evidencia del Corte 5. No contiene
entrevistas, contactos, auditorías ni resultados de campo ejecutados.

## Artefactos

- `PROTOCOLO.md`: guiones, secuencia común, reglas de evidencia y paradas.
- `outputs/corte-5/Instrumentos-Corte-5.xlsx`: libro maestro con las muestras,
  campos, validaciones y matriz de cohorte.
- `evidence/local/`: copias de trabajo con observaciones reales. Está ignorado
  por Git para que una sesión de campo no termine publicada por accidente.

## Antes de una sesión autorizada

1. Copiar el libro maestro a
   `evidence/local/AAAA-MM-DD_<actividad>_v01.xlsx`.
2. Confirmar que el participante o negocio usa sólo el código anónimo ya
   preparado (`C01`, `S01`, `N001`, etc.).
3. Registrar una fila por observación y marcarla `observado`. Una interpretación
   posterior se marca `inferido`; una ausencia de evidencia, `desconocido`.
4. No escribir nombres, teléfonos, correos, usuarios sociales, direcciones,
   coordenadas, chats, documentos, pagos ni ventas declaradas.
5. Al terminar, revisar la copia contra el límite de privacidad y conservar la
   fuente bruta sólo fuera del repositorio público.

## Qué puede decidir este corte

La matriz compara capacidad de mantenimiento, consultas reales, alternativas,
tiempo, pasos y claridad del handoff. No asigna una cohorte ganadora por fórmula:
la selección pertenece a Ale después de revisar evidencia suficiente y sus
límites.

Registros, tráfico, aperturas de WhatsApp o filas completadas no son éxito. El
piloto debe poder detenerse cuando la frescura dependa del equipo, no haya
alternativas útiles o el handoff confunda.

## Límite vigente

Preparar y verificar estos instrumentos está autorizado. Contactar personas o
negocios, ejecutar trabajo de campo, publicar, desplegar, configurar proveedores,
usar credenciales o gastar requiere autorización separada de Ale.
